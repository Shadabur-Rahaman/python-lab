# Interactive lesson standard

Start with a concrete task. Explain the smallest useful concept, then invite a prediction and a real run. Provide a meaningful error to debug and a small extension to build. Give specific feedback and keep mastery tied to existing completion and assessment rules. Put a model next to the explanation, label it as a model, and let the editor report the actual program result. Provide existing references and keep working examples, practice and quizzes reachable.
