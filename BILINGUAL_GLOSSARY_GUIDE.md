# Bilingual glossary

The registry contains 28 entries. It preserves the original 26 English definitions and adds Iterable and Loop body. The additional Hindi explanations are authored in source. Search indexes English, Hindi and aliases. Use the language selector, alphabet and topic filters to browse terms. Favorites, recently opened entries and language preferences are stored on the device. Flashcards let you recall a definition before revealing it.

Related terms appear as explicit buttons below chapter explanations. Activate them by click, tap, double-click, Enter or Space. Escape or Close returns focus to the button. The implementation keeps source code and examples intact. Glossary entries have stable links such as `#/glossary/identifier`.

Maintain the registry in `src/data/glossary.ts`. Preserve each existing ID, use familiar Hindi, and keep Python keywords and built-ins spelled as they appear in code. Link a real lesson and syntax topic and run the bilingual browser tests when adding a term. The glossary stores preferences separately from student progress and snippets.

Standalone glossary quizzes, difficulty filtering, dedicated Hinglish variants and detailed English examples for every term are future additions.
