# Syntax Academy visual audit

Each of the 30 baseline routes rendered a syntax and symbols section and has one existing editable demonstration. The shared topic layout now pairs annotated syntax with the editor at wide widths and provides a compact Reference mode. The existing topic explanations, practice, and corrections supply the teaching content. Topic-specific simulations were added to chapters only.
