# Curriculum map

Learners can open any published lesson. Prerequisites describe the knowledge needed to work independently. Chapters 0–12 retain their original links and progress IDs.

| Level | Suggested preparation | Available in this preview | Planned additions |
| --- | --- | --- | --- |
| 0 · Before programming | None | Chapter 0 introduces instructions, algorithms and Python execution. | Hardware and software, flowcharts, pseudocode, terminals, local installation, VS Code, environments and Colab. |
| 1 · Python beginner | Level 0 | Chapters 1–12 cover syntax, variables, types, input, operators, strings, conditions, loops, collections, functions and mini-projects. | Recursion and a fuller debugging sequence. |
| 2 · Python intermediate | Loops, collections and functions | Chapter 13 covers comprehensions, unpacking, sorting, zip and enumerate. Chapter 14 covers paths, JSON and exceptions. | Iterator protocol, generators, module and package structure, regular expressions, CSV, dates, typing, virtual environments, pip, Git and introductory testing. |
| 3 · Object-oriented Python | Functions and mutable collections | Chapter 15 covers instance state, initialization, methods and aliasing. | Composition, inheritance, MRO, polymorphism, properties, dataclasses, protocols and operator overloading. |
| 4 · Advanced Python | Levels 2 and 3 | — | Closures, decorators, context managers, advanced generators, descriptors, metaclasses, memory, typing, concurrency, profiling and caching. |
| 5 · Professional engineering | Intermediate Python and testing fundamentals | — | Project structure, packaging, dependency management, pytest, fixtures, mocking, coverage, linting, formatting, static checks, logging, configuration, secrets handling, CLI tools, CI/CD, Docker and deployment. |

The new project, **Inventory Report from JSON**, follows chapters 13 and 14. The original ten projects remain available.
