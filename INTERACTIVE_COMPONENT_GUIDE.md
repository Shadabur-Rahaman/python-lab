# Interactive component guide

Add a scenario in visualModels.ts for a stable chapter ID. Supply a control label, a finite set of options, three state descriptions, an accurate memory cue, and a realistic application. ConceptModel maps those options to labeled stages. Treat the result as a teaching model for controlled values. CodeLab owns real Python execution, starter code and saved drafts. The chapter output check compares the learner's prediction to the published starter output.
